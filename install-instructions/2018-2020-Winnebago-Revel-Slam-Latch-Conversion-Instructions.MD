# 2018-2020 Winnebago Revel Slam Latch Conversion Instructions

### While this kit can be installed yourself, for best results we recommend having it professionally installed.

### Tools Needed:
- Drill
- Phillips bit
- Drill bits
- Flat head screw driver

## Installation:
1. Remove the drawer or cabinet door. The drawers have a plastic tab on either side, pressing it one of the two directions releases the catch and allows the drawer to be removed. For the cabinet door, remove the screws from the hinges on the cabinet door side.
![PXL_20260618_135637488.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_135637488.jpg)

2. Remove the original latch.
![PXL_20260618_134132817.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134132817.jpg)
![PXL_20260618_134140066.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134140066.jpg)
![PXL_20260618_134210364.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134210364.jpg)

3. If you press the housing from the inside, you can create enough of a gap on the front to slowly work this out with a flat head screwdriver.
![PXL_20260618_134216453.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134216453.jpg)
![PXL_20260618_134226758.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134226758.jpg)

4. Install the jig alignment insert.
![PXL_20260618_134234479.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134234479.jpg)
![PXL_20260618_134245550.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134245550.jpg)
![PXL_20260618_134337888.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134337888.jpg)

5. Install the jig.
![PXL_20260618_134347582.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134347582.jpg)

6. Move the jig or rotate the insert until the lines are aligned. There is a small opening in the middle of the insert where you can use a flat head screwdriver.
![PXL_20260618_134418129.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134418129.jpg)

7. With everything aligned, install the clamps.
![PXL_20260618_134432572.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134432572.jpg)
![PXL_20260618_134501775.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134501775.jpg)
![PXL_20260618_134504980.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134504980.jpg)

8. Remove the jig alignment insert and triple check that everything looks aligned, square, etc.
![PXL_20260618_134548438.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134548438.jpg)

9. Following the next steps, you can use either a 2 inch hole saw in a drill or a flush-cut router bit in a wood router, to cut the opening.

10. Remove the jig.
![PXL_20260618_134814797.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134814797.jpg)
![PXL_20260618_134838132.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134838132.jpg)

11. Insert the slam latch.
![PXL_20260618_134950414.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_134950414.jpg)

12. Install the rear hardware.
![PXL_20260828_170525198.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260828_170525198.jpg)
![PXL_20260828_170623662.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260828_170623662.jpg)

13. Using the original latch strike plate, remove the screws, rotate the strike plate 180 degrees and reinstall.
![PXL_20260618_135538999.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_135538999.jpg)
![PXL_20260618_135545775.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_135545775.jpg)

14. Reinstall the drawer or cabinet door. Test the alignment of the strike plate, if the latch does not keep the drawer or cabinet door from opening the strike plate needs adjusted (or bent) forward. If the latch catches but there is play, the strike plate needs adjusted (or bent) backwards.
![PXL_20260618_135733133.jpg](./2018-2020-Winnebago-Revel-Slam-Latch-Conversion-images/PXL_20260618_135733133.jpg)

15. Repeat the same steps for the other drawers and cabinet doors using the correct jig.
