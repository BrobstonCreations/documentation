
### 5. Install frame replacement trim

1. Remove the cabinet latches from the original frame and transfer them to the new lower frame replacment. Take note that holes (not slots) are used on the latch and orient the replacement frame with the latch holes on the frame side set back as pictured.
![PXL_20260822_164541558](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164541558.jpg)
![PXL_20260822_164629103~2](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164629103~2.jpg)
![PXL_20260822_164643624~2](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164643624~2.jpg)
![PXL_20260822_164723949.MP](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164723949.MP.jpg)

2. Flip the replacement frame upside down and install the second latch for the top.
![PXL_20260822_164803915](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164803915.jpg)

3. Locate the lower frame replacement, six 2 inch wood screws, and two 1 1/2 inch wood screws.
![PXL_20260822_164950109](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164950109.jpg)

4. Slide the lower frame replacment into the lower pantry opening. It may be a tight fit, if you insert as pictured (the bottom first, at an angle, then rotate the bottom in, then rotate up) it may be easier.
![PXL_20260822_164837044](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164837044.jpg)
![PXL_20260822_164841194](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164841194.jpg)
![PXL_20260822_164858961](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164858961.jpg)

5. A few new holes will need drilled. Be sure the frame is square before making any new holes. I would recommend making one new hole at a time, making sure the frame is square to the pantry before each, and I would recommend working in a clockwise pattern starting in the top right. To create a new hole in the metal, I first attempted to screw a new screw in, which leaves a mark similar to a center punch, then I removed the lower replacement frame and used a drill bit to drill a new hole. I then screwed the new frame in using all newly created holes and proceeded to create the next hole. For the new screw holes that go into wood you can skip drilling and instead using the self-tapping tip on the screw; I would not recommend doing this into the metal as you risk snapping the screw.
