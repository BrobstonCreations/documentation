
### 6. Install pantry drawer

1. Install the pantry. I typically lift but the underside of the top fixed shelf with both of my hands and focus on lining up the front left and bottom left drawer slides, as long as the slides are aligned well the opposite side will align without any problems. Push the pantry in all the way, I've found that the first time it goes in with resistence, but it seems to be a lot easier the second time.
![PXL_20260822_164132483](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164132483.jpg)
![PXL_20260822_164247779.MP](../Winnebago-Revel-Slideout-Pantry-images/PXL_20260822_164247779.MP.jpg)
2. Once the pantry drawer is in, we need to adjust the strike plate that the latch hooks on. With strike plate and latch installed, close the pantry all the way. Grab the pantry door by the top and the bottom and without touching the latch, see if there is any movement if you pull the drawer outwards. If there is, the strike plate needs adjusted backwards. Adjust and retest. If the latch is not making it to the strike plate, the strike plate needs adjusted forward.
